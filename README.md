# Панель управления магазином

Учебный проект для управления интернет-магазином: административная панель и серверное API с базой PostgreSQL.

## Возможности

- Товары, варианты, категории и бренды.
- Заказы, статусы, доставки, клиенты и сотрудники.
- Корзина, адреса пользователей, JWT-авторизация и разграничение доступа.
- Документация API в формате OpenAPI и экспорт структуры базы данных.

## Технологии

Node.js, Express, PostgreSQL, JavaScript, HTML, CSS, JWT и bcrypt.

## Запуск

1. Установите Node.js и PostgreSQL 18.
2. Выполните `npm install`.
3. Создайте пустую базу и восстановите структуру из `schema.sql`. Подробности — в [DATABASE.md](DATABASE.md). Экспорт не содержит пользователей приложения и справочных данных.
4. Скопируйте `.env.example` в `.env` и заполните параметры подключения и секрет JWT.
5. Выполните `npm start` и откройте `http://localhost:3000/admin`.

Для входа потребуется создать пользователя с ролью администратора в базе. Скрипта первичной настройки и тестовых данных в проекте пока нет. Структура базы получена из существующей системы; восстановление в чистой базе и все зависимости функций и триггеров требуют дополнительной проверки.

## API и база

[Спецификация OpenAPI](openapi.yaml) открывается в Swagger Editor. [Описание базы](DATABASE.md) содержит перечень таблиц и связей. Проверка HTTP-сервера: `/api/health`.

## Ограничения

Проект находится в разработке. Миграции базы не добавлены; команды `setup` и `check-db` в package.json ссылаются на отсутствующие файлы.
